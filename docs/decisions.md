# Architecture Decision Log

## ADR-001
Use Azure PostgreSQL Flexible Server as platform database.

## ADR-002
Use Grafana as primary visualization platform.

## ADR-003
Use Azure Container Apps for MVP.

## ADR-004
Use Service Bus for work scheduling.

## ADR-005
Use Event Hub for telemetry ingestion.

## ADR-006
Implement Zero Trust AI architecture.

## ADR-007
Implement a composite database health scorecard (score out of 10, default 10/10). Scores are computed by a scoring engine from collected signals and stored in PostgreSQL. Deductions are displayed inline with metric values in Grafana drill-down view. Signal library starts with 3 MVP signals and grows over time.

## ADR-008
Implement AI natural language query interface. Users can ask plain-English questions about their database estate. The AI context builder assembles health scores, incidents, drift signals, and anomalies before calling Azure OpenAI. The same engine powers the daily email digest.

## ADR-009
Daily digest delivered by email only. No Grafana panel. Digest is generated by the AI query engine on a scheduled morning trigger and sent via SMTP.
